## 判定口径（与契约逐条对应）

| # | 契约定性 | 实测结论 |
| --- | --- | --- |
| ① | `SELF` = 创建人本人**或**创建人所属部门 | ✅ 实测一致（`data_scope='4'`） |
| ② | `DEPT` = 合同所属部门命中 `sys_dept.ancestors` 链、含下级为默认 | ✅ 实测一致（`data_scope='3'`；⚠ 与 `DEPT_AND_CHILD` 收敛为同一值，判别力靠**不同夹具**取得，见 DEV-ENV §6.49） |
| ③ | 多角色取并集 | ✅ 运行期两角色用例（整集 3 行逐 id 一致）+ `grep -rn "并集"` 7 处 + 单测 4 条 |
| ④ | 范围外按标识直查详情返回 403 | ✅ 24 条原始响应体 `HTTP=200` + `code=403`（无 500、无 HTTP 层 403） |
| ⑤ | 超管可见全部 | ✅ 矩阵内单列档位 |

## 运维须注意的一条（口径与界面标签不一致）

`sys_role.data_scope` 的角色页标签与 B3 服务端口径**有偏差**：`'4'` 实际判成
「本人创建**或**本人所属部门及以下」、`'5'` 判成「仅本人创建」。
**照角色页标签选 `'4'` 会偏宽**（比"本部门及以下"多出"本人创建但不在本部门"的行）。
配范围时请按**值语义**而不是标签来选（详见 DEV-ENV §6.49）。
