# Spec Delta

## Purpose

定义内置打印模板的**按单据类型选用**与**版式常量真源**：系统 SHALL 内置四套版式（合同 / 资金 / 事项 / 付款），由单据模板显式选择，并在未配置自定义打印模板时作为兜底版式生效。

## ADDED Requirements

### Requirement: 内置版式注册表
系统 SHALL 提供且仅提供 4 套内置打印版式，以稳定键标识：`contract`（集团合同类文件流转审批单）、`fund`（集团资金审批单）、`matter`（集团事项类打印审批单，默认取"集团请示文件流转审批单"版式）、`payment`（付款申请单）。

#### Scenario: 内置版式清单可查询
- **WHEN** 具备打印模板查看权限的用户请求内置模板清单
- **THEN** 系统返回恰好 4 条记录，键分别为 `contract` / `fund` / `matter` / `payment`
- **AND** 每条记录携带该版式的展示名称

#### Scenario: 版式键之外的值被拒绝
- **WHEN** 保存单据模板时提交 `builtin_print_key` 为 `contract`/`fund`/`matter`/`payment` 之外的任意值
- **THEN** 系统拒绝该次保存并给出明确错误提示
- **AND** 该单据模板的 `builtin_print_key` 保持原值不变

### Requirement: 单据模板绑定内置版式
每个单据模板 SHALL 持有唯一的 `builtin_print_key`，用于在未配置自定义打印模板时决定打印版式。

#### Scenario: 新建单据模板的默认绑定
- **WHEN** 新建一个未显式选择内置版式的单据模板
- **THEN** 该模板的 `builtin_print_key` 为 `contract`
- **AND** 其打印件沿用集团合同类文件流转审批单版式

#### Scenario: 按单据类型选用版式
- **WHEN** 某资金类单据模板被选择为 `fund` 并执行打印
- **THEN** 打印件采用集团资金审批单的标题与栏目
- **AND** 打印件不出现合同类专有栏目（合同编号、合同全称、履约期限等）

#### Scenario: 存量模板零回归
- **WHEN** 升级前已存在的单据模板在升级后执行打印
- **THEN** 该模板的 `builtin_print_key` 取默认值 `contract`
- **AND** 打印件的标题与版式与升级前逐项一致

### Requirement: 有效打印模板的优先级链
系统 SHALL 按固定优先级解析一次打印所使用的模板：显式传入的打印模板标识 > 该单据模板下处于启用状态的配置模板 > 内置版式。该优先级链 MUST NOT 因本次变更而改变。

#### Scenario: 显式标识优先
- **WHEN** 请求打印时显式传入了一个配置模板标识
- **THEN** 系统使用该配置模板，不读取该单据模板的启用行与内置版式

#### Scenario: 启用行优先于内置
- **WHEN** 请求打印时未传打印模板标识，且该单据模板下存在一条启用状态的配置模板
- **THEN** 系统使用该启用配置模板，不读取内置版式

#### Scenario: 无启用行时回退内置
- **WHEN** 请求打印时未传打印模板标识，且该单据模板下不存在启用状态的配置模板
- **THEN** 系统按该单据模板的 `builtin_print_key` 选用内置版式
- **AND** 该结果的模板标识为空，前端据此判定为内置模板

### Requirement: 内置版式常量以后端为唯一真源
内置版式的标题与栏目字段映射 SHALL 由服务端作为唯一真源提供；客户端 MUST NOT 内置第二份副本。

#### Scenario: 客户端拉取内置版式映射
- **WHEN** 打印模板配置页需要"填入内置版式"的起点内容
- **THEN** 该内容由服务端接口按版式键返回
- **AND** 客户端源码中不存在与任一内置版式等价的字段映射常量副本

#### Scenario: 修改一处即全局生效
- **WHEN** 调整某个内置版式的栏目或字段映射并重新部署
- **THEN** 打印件与配置页的"填入内置版式"同时反映该调整
- **AND** 无需修改客户端代码

### Requirement: 内置版式四套栏目与字段来源
每套内置版式 SHALL 逐项输出其栏目，并按已确认的字段来源取值：`contract` 沿用已实现的 13 行映射；`fund` 输出审批单位、事项分类、计划类别、付款归属期、资金审批内容及三栏签名区；`matter` 输出公文来源（报送单位/报送人/报送时间）、文件编号、信息名称、文件类型、加急程度、文件概要、公文接收及处理、公文关联单位处理、集团领导意见、印鉴证照管理部门、公文回传及归档；`payment` 输出抬头、收款信息、付款信息与签批栏。

#### Scenario: fund 版式栏目齐备
- **WHEN** 用 `fund` 内置版式打印一张资金审批单
- **THEN** 打印件包含「审批单位」「事项分类」「计划类别」「付款归属期」「资金审批内容」五个栏目
- **AND** 事项分类取表单 `matterCategory`、计划类别取 `planType`、付款归属期取 `paymentPeriod`、资金审批内容取 `fundContent`、审批单位取发起人所属公司

#### Scenario: matter 版式栏目齐备
- **WHEN** 用 `matter` 内置版式打印一张事项类单据
- **THEN** 打印件包含「公文来源（报送单位/报送人/报送时间）」「文件编号」「信息名称」「文件类型」「加急程度」「文件概要」「公文接收及处理」「公文关联单位处理」「集团领导意见」「印鉴证照管理部门」「公文回传及归档」栏目
- **AND** 文件编号取 `docNo`、信息名称取 `matterTitle`、文件类型取 `docType`、加急程度取 `urgency`、文件概要取 `summary`

#### Scenario: payment 版式栏目齐备
- **WHEN** 用 `payment` 内置版式打印一张付款申请单
- **THEN** 抬头输出日期与计划内/计划外
- **AND** 收款信息输出收款单位名称 / 开户银行 / 账号，分别取 `payeeName` / `payeeBank` / `payeeAccount`
- **AND** 付款信息输出付款单位名称 / 开户行 / 一级分类 / 付款归属期 / 二级分类 / 回单 / 银行付款用途 / 结算方式 / 付款事由 / 金额 / 金额大写 / 备注
- **AND** 签批栏输出经理 / 财务 / 部门负责人 / 财务负责人 / 制单人 / 领款人，其中制单人取发起人

### Requirement: 响应契约不包含死字段
打印聚合响应 MUST NOT 暴露从未被赋值的字段，以免契约文档产生误导。

#### Scenario: 打印聚合响应无死字段
- **WHEN** 客户端请求某单据的打印聚合数据
- **THEN** 响应体中不存在 `formSchema` 字段
- **AND** 打印件的字段表仍取单据自身保存的表单快照与生效模板的字段映射

### Requirement: 配置页支持内置与自定义两种模式
打印模板配置页 SHALL 同时支持"选择内置模板"与"选择自定义模板"两种模式，并给出实时预览。

#### Scenario: 选择内置模板
- **WHEN** 管理员在配置页选择"选择内置模板"并指定一个版式键
- **THEN** 页面展示该版式的栏目作为预览
- **AND** 保存后该单据模板的 `builtin_print_key` 为该键

#### Scenario: 选择自定义模板
- **WHEN** 管理员在配置页选择"选择自定义模板"并编辑字段映射
- **THEN** 页面按当前字段映射实时刷新预览
- **AND** 保存后该单据模板下新增或更新一条配置模板记录，内置版式不再参与该单据的打印
