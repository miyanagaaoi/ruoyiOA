2.0 新增
留痕：从「尽力而为」改成硬门禁
现状
先渲染打印、再尽力写 t_print_log；写日志失败只 warning，用户已经拿到纸了。
2.0
先写日志 → 写成功才渲染打印；写日志失败则阻断打印并提示「打印留痕失败，请重试」。
打印日志字段不变（人 / 时间 / IP / 页数），详情页的「打印记录」照旧可见。
为什么留痕要变硬
审计要求"打印必留痕"。现状的 catch-only 写法在并发或库抖动时会静默漏记。
不改的部分
打印日志表结构、详情页打印记录区块、水印文案、页脚「第 X 页 / 共 Y 页」全部沿用 V1。
