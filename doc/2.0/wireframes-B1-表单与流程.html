S28越权与失败态 · 必须显式、必须可重试AC-49 / AC-50 / AC-56 / AC-59
异常态合集
① 越权发起（服务端 403，且不落库）
发起「集团投资审批」
403 · 你不在该单据的可发起范围内。请联系流程管理员把你的账号或所在部门加入「谁可以提交该审批」。
数据库中：无新增表单数据、无新增流程实例。
② 无权限编辑 / 发布流程（服务端 403）
403 · 你不是该模板的流程管理员，也没有本模板的编辑权限。
界面同时把「③ 流程设计」页签置为只读，并提示谁可以编辑。
③ 流程发布失败（显式 + 可重试）
发布未完成：流程引擎已部署，但模板绑定写入失败。系统已回滚本次部署（或保留为待重试状态）。
重试发布查看详情不会出现「界面说发布了但发起时报找不到流程」
④ 关联审批浮窗越权
403 · 无权查看该单据。浮窗不展示任何字段值。
共同要求
所有权限判定必须服务端强制；前端隐藏只是体验，不构成防护。
回写只能落在启用行
模板编辑若"换新 ID"，发布回写会写到废弃行，打印模板与节点字段权限会失联。B1 的第一件事就是把它改成原地更新（见 PRD 8.3 / REQ-DATA-004）。
部分成功
前端必须能区分：模板已保存 / 流程未发布 / 发布失败可重试。
