必须同时满足的三项实现要求
显式事务

行锁
结存行 SELECT … FOR UPDATE，把"读—改—写"保护起来
唯一索引 + 重试
结存表 (物料, 仓库) 唯一索引；首次插入冲突时捕获重复键并重试
为什么参考实现看不出这个问题
它跑在 SQLite + WAL 上，写操作串行化，"先查后插结存行"的竞态被掩盖了；其源码注释已经预告"切到 PostgreSQL 要加行锁"。MySQL 下必须显式补上。
