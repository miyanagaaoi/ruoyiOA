## 3. 关键决策记录

### 3.1 业务决策（Q1–Q4，已确认）

| # | 问题 | 结论 |
| --- | --- | --- |
| Q1 | 并行会审的合流条件 | **全部部门审完**才推进 |
| Q2 | 驳回后是否留痕 | **保留**（任务置「已作废」，不物理删除） |
| Q3 | 同一人多节点是否合并待办 | **不合并**；预留节点级开关「同一审批人是否自动通过」（默认每次都审） |
| Q4 | 法务节点是否预置系统规则 | **不预置**；由管理员在具体流程中固定为主链必经节点，提交人「其他会审部门」多选**不含法务** |

### 3.2 技术决策

| 决策 | 理由 | 影响 |
| --- | --- | --- |
| 条件分支**必须**编译为排他网关，兜底走 default 流 | BPMN 原生语义下用户任务的**多条出口为真会并行执行**，条件分支会静默退化成并行分支 | 编译器硬约束，已写进 PRD |
| 并行会审编译为**多实例用户任务**，不用并行网关 | 已实测：空集合自动跳过、全部完成自动合流、或签 `${nrOfCompletedInstances >= 1}` 生效 | 无需并行网关与会签网关配对 |
| **并行分支不设「其他情况」兜底** | 并行=多支同时流转，再加"没命中走这里"自相矛盾（飞书此处有语义混淆，刻意不照抄） | 与飞书不一致，已在文档注明 |
| 选中态用**路径寻址** `[节点下标, 泳道下标, …]` | 旧实现 `{kind,index,branchId,subIndex}` 只能表达两层，嵌套一深即失效 | 为将来放开嵌套留好接口 |
| 画布尺寸收敛为**三个 CSS 变量** | 原先 `14px`/`16px` 各硬编码 2–3 处，改一处忘另一处就断线 | `--node-w` `--lane-gap` `--stub-h` |
| 同级卡片**统一确定宽度** `--node-w: 280px` | 靠 max-content 各自算会被长文本撑开，导致左右不齐 | 同级泳道因此自然等宽 |
| 泳道头**固定 80px 等高** | 头部内容多少不一（有条件的 2 行、兜底的 1 行），自适应会让下方卡片从不同 y 开始 | 条件文本 `-webkit-line-clamp: 2` 截断以保高度恒定 |
| 分叉/汇合线由**每条泳道各画一段**拼接 | 原 `calc(50% / var(--lanes))` 只在泳道等宽时成立，改为内容宽度后必然错位 | 与泳道宽度解耦，1/2/N 条都对 |
| 配置面板由常驻右栏改为**抽屉** | 画布占满主内容区 | `el-drawer` 540px |
| 首页/登录页视觉采用 **oa-web 设计令牌** | 与集团 OA 保持同一产品语言 | 卡片用 1px 细线不用阴影；层级靠字重与颜色 |

## 8. 过程中的坑（供下次避雷）

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| Maven 增量构建假成功 | `mvn package` 报 BUILD SUCCESS 但 jar 里是旧的 `ruoyi-workflow` | **必须 `clean package`**；`maven-jar-plugin` 被跳过 + 可复现构建的 `outputTimestamp` 会掩盖时间戳 |
| BPMN 条件表达式 | 写成 `${A} == 'B'` 运行期报 `condition expression returns non-Boolean` | 整句包进**一对** `${ }`：`${A == 'B'}` |
| 条件判定时机 | 首节点未完成就断言分支，测试必失败 | 网关在**上一个用户任务完成后**才求值 |
| 校验器漏检分支子节点 | 好流程误报 V-1「只有 1 个审批节点」 | 递归遍历分支子链，链内作用域判重名 |
| `AjaxResult.success(String)` | 重载解析到 message，XML 落进 `msg` 字段 | `AjaxResult.success()` 后 `ajax.put("xml", …)` |
| Sass `/deep/` | `Syntax Error: expected selector` | 用 `::v-deep` |
| `npm run dev` 空日志退出 1 | `npm.ps1` 被执行策略拦住 | 用 **`npm.cmd`** |
| Windows 文件锁 | 编辑报 `ReplaceFileW EIO (Win32 1175)` | webpack 正在读该文件，**重试即可** |
| Liquibase 二次启动失败 | `ClassCastException: LocalDateTime cannot be cast to Date` | 每次冒烟前重建库 |
| mysql 中文路径 | `source` 报 `Failed to open file` | SQL 复制到 ASCII 路径再执行 |
| 登录需 RSA 加密口令 | 明文登录失败 | `node tools\rsa-encrypt.js "admin123"` |
| `box-sizing` 不统一 | 定宽卡片比泳道头**各宽 1px** | 所有定宽元素统一 `border-box` + 锁 `min/max-width` |
| **HMR 保留组件状态** | 刷新后抽屉仍带着上次选中的分支打开 | 这是开发期现象，**整页刷新会重置**，非缺陷 |
| 凭 CSS 推理猜布局 | 连续 3 轮改宽度都没命中真因（真因是**泳道头高度不等**） | **要截图**——用户一张图就定位了根因 |
