### 2.2 环境事实 B —— 演示账号 token 静默过期（**这一条才是"合流假象"的触发条件**）

```

profile superAdmin -> code=200      ← 它被别的脚本反复使用，RuoYi 每次请求都给它滑动续期

**关键**：RuoYi 的认证失败**不是 HTTP 401，而是 HTTP 200 + body `code=401`**：

```

→ HTTP status = 200
→ body = {"msg":"请求访问：/biz/flow/submit，认证失败，无法访问系统资源","code":401}

⇒ **既不抛异常、`catch` 也不进、脚本"看不到"**。

## 4. 根因（分层，含历史那一半）

### 4.1 主因（本轮可复现、可稳定触发）：**验收入口静默吞 401 + 凭据静默过期**

见 §2.2 / §2.3 / §3。一句话：**引擎没错，是"审批根本没发生"被当成了"引擎不合流"。**

### 4.2 历史主因（2026-10-04，**已在源码修掉并早已部署**）：完成条件写法

`doc\缺陷-并行会审全部完成不合流.md` 记的 10-04 问题真实存在：旧编译器给 `joinMode=ALL` 生成了

```xml
<completionCondition xsi:type="tFormalExpression"><![CDATA[${nrOfCompletedInstances == nrOfInstances}]]></completionCondition>
```

而本环境（Flowable 6.7.2）的并行多实例计数器是**派生的标记变量**，不是普通整数：

```
ACT_RU_VARIABLE：TYPE_=integer                               NAME_=nrOfInstances          LONG_=2/4
                 TYPE_=bpmnParallelMultiInstanceCompleted     NAME_=nrOfCompletedInstances TEXT_=<MI根执行id> TEXT2_=completed LONG_=NULL
                 TYPE_=bpmnParallelMultiInstanceCompleted     NAME_=nrOfActiveInstances    TEXT_=<MI根执行id> TEXT2_=active    LONG_=NULL
```

（值由 `org.flowable.engine.impl.variable.ParallelMultiInstanceLoopVariableType#getValue` 在读取时现算：
`nrOfCompletedInstances = nrOfInstances - 活动子执行数`；这是 6.7.2 对多实例计数的优化，不是脏数据。）

**修复动作（已存在于代码，commit `5f7ee03`，2026-10-04 15:10）**：`joinMode=ALL` **不再生成完成条件**，
把"全部完成才合流"交回引擎的原生语义（所有实例完成后自然离开）；只有 `ANY`（或签）保留 `${nrOfCompletedInstances >= 1}`。
`SimpleFlowCompiler.java` 现状（本轮核对）：

- 并行分支：`e.miCompletion = JOIN_ANY.equals(joinMode) ? "${nrOfCompletedInstances >= 1}" : null;`（第 242-244 行）
- 会签/或签分支：`M_OR` 才给 `${nrOfCompletedInstances >= 1}`，AND/SEQ 传 `null`（第 592-596 行）；`appendMultiInstance` 判空后才写 `completionCondition`（第 611-614 行）
- **不要**再把 `==` 加回来（旧的坑已在注释里写死，见 `SimpleFlowCompiler.java:232-244`）

**运行态证明（本轮，不是"看源码猜"）**：

| 证据 | 内容 |
| --- | --- |
| 历史部署产物（`rad_oa_b1copy`，B4 之前库副本里的真实 BPMN） | `testParallel:1`(bytearray `1090010`)**带** `${nrOfCompletedInstances == nrOfInstances}`；`testParallel:2`(`1092502`)**不带**；`testCombo:1`(`1090014`)**带**；`testCombo:2`(`1097565`)**不带**；`testParallelAny:1`(`1090111`) = `${nrOfCompletedInstances >= 1}` |
